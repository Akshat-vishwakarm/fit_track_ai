## ✨ Overview

**FitTrack AI** is a personal fitness tracking platform that brings your daily fitness journey into one place.

Instead of using separate apps for habits, workouts, nutrition, goals, and progress, FitTrack AI combines them into a single fitness dashboard with AI-powered nutrition analysis and an architecture designed for future ML integration.

The project is being built as a personal **fitness and self-improvement OS**, with the goal of tracking real-world progress over time.

## ⚡ Features

### 📊 Dashboard

Get a centralized overview of your fitness journey.

- Daily activity
- Habit progress
- Workout information
- Nutrition summary
- Goals
- Body progress
- Streaks
- Daily completion

### 🔥 Habit Tracker

Create and manage your own daily habits.

- Create custom habits
- Mark habits complete
- Daily checkbox tracking
- Track streaks
- View habit history
- Weekly progress
- Habit completion analytics
- Build consistent routines

Example habits:

- ⏰ Wake up on time
- 💪 Gym / Workout
- ❄️ Cold shower
- 💧 Drink 4L+ water
- 🥗 Eat healthy
- 📚 Read / Study
- 💻 Skill practice
- 🚫 Limit social media
- 🧘 Meditation
- 📝 Journaling
- 🌙 Sleep 7+ hours
